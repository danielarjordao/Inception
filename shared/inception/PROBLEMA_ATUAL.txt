================================
PROBLEMA ATUAL - MariaDB
================================

SINTOMA:
--------
O container MariaDB entra em loop de reinicialização (Restarting).
Nginx e WordPress sobem normalmente.

ERRO NO LOG:
-------------
mariadb  | 2025-11-25 10:22:30 0 [ERROR] Can't start server : Bind on unix socket: No such file or directory
mariadb  | 2025-11-25 10:22:30 0 [ERROR] Do you already have another server running on socket: /run/mysqld/mysqld.sock ?
mariadb  | 2025-11-25 10:22:30 0 [ERROR] Aborting

CAUSA RAIZ:
-----------
O diretório /run/mysqld/ não existe dentro do container MariaDB.
O MariaDB precisa desse diretório para criar o socket Unix (mysqld.sock).
Sem esse diretório, o MariaDB não consegue iniciar e o container reinicia infinitamente.

SOLUÇÃO APLICADA:
-----------------
Adicionadas 3 linhas no arquivo: srcs/requirements/mariadb/Dockerfile

Após a linha que define permissões do mariadb.cnf, foram adicionadas:

# Create directory for MariaDB socket
RUN mkdir -p /run/mysqld

# Set ownership of socket directory to mysql user
RUN chown -R mysql:mysql /run/mysqld

Estas linhas foram inseridas ANTES de copiar o mariadb_init.sh.
